# HappyWrite v1.4.3 - AI 驱动的网文写作助手

> **v1.4.3 更新** (2026-05-28) — 人物属性改为键值对表单编辑，告别手写 JSON。详见 [更新日志](#更新日志)。

HappyWrite 是一款桌面端网文写作软件，深度集成 AI 能力，帮助作者从灵感到完稿高效创作。支持树形大纲与思维导图双视图规划、多模型 AI 辅助写作、角色世界观管理等功能。

## 功能特性

### 写作核心
- **富文本编辑器** — 基于 TipTap，支持标题层级、粗斜体、下划线等格式
- **Markdown 快捷输入** — `#` 变标题、`**`变粗体、`>` 变引用块、`---` 插入分割线，输入即自动转换
- **键盘快捷键** — `Tab/Shift+Tab` 缩进、`Cmd+K` 插入链接、`Cmd+←/→` 快速切换章节、`Cmd+Enter` 插入分割线
- **快捷键面板** — 按 `?` 弹出全局快捷键速查面板，分组展示所有快捷键
- **打字机模式** — 光标自动保持在屏幕中央，行聚焦高亮当前段落，其余半透明护眼。RAF 节流 + 原生 scrollIntoView，流畅不抖动
- **专注分屏** — 专注模式下可开启分屏，编辑器右侧显示大纲/人物参考面板，可拖拽调整比例
- **多主题系统** — 暖黄 / 护眼绿 / 暗黑增强 / 冷白 / 纸张 5 套预设背景主题
- **排版自定义** — 字体、字号、行高、段落间距、页宽自由调节，实时预览
- **卷/章管理** — 树形目录，拖拽排序，章节预加载实现秒切
- **自动保存** — 1.5 秒防抖自动保存，不怕丢失内容
- **智能拆分** — 章节超过 8000 字自动提示，一键拆分为新章节
- **章节模板** — 5 种预设结构（空白/三幕/起承转合/悬念开篇/日常铺垫），新建章节时可选
- **专注模式** — `Ctrl/Cmd+Shift+F` 隐藏所有面板，沉浸式写作
- **字数统计** — 中英文混合计数，每日字数目标追踪，写作热力图
- **写作日历** — 月度热力图 + 连续打卡天数 + 里程碑徽章（7/30/100/365 天），写作习惯可视化
- **启动优化** — BrowserWindow `ready-to-show` + 骨架屏，消除白屏闪烁

### AI 写作助手
- **6 种 AI 模式** — 续写、润色、灵感、人物生成、全文审稿、章节摘要
- **选中文本 AI 操作** — 选中文字后浮出菜单，一键润色/扩写/缩写，直接替换原文
- **审稿模式** — AI 从节奏、人物一致性、情节逻辑、表达优化、总体评价 5 个维度给出建议
- **摘要模式** — 一键生成章节摘要，可直接保存到笔记
- **智能上下文注入** — 自动将角色设定、世界观、大纲信息注入 AI 请求，让回复更贴合故事
- **AI 智能起名** — 角色名、地名、技能/物品等 6 种类型 × 5 种风格，AI 批量生成备选
- **AI 写作人设** — 配置个人写作风格标签、叙事偏好、自定义指令和参考文段，全局注入所有 AI 交互
- **会话管理** — AI 对话历史保存、切换、删除，支持多线并行讨论

### 多模型支持
内置 **14 个国内外主流大模型**，开箱即用：

| 分类 | 提供商 |
|------|--------|
| 国际 | Claude (Anthropic), OpenAI, Google Gemini, Mistral, Groq |
| 国内 | DeepSeek, 通义千问 (Qwen), 智谱 GLM, 月之暗面 (Kimi), 百川, 豆包, MiniMax |
| 本地 | Ollama — 自动发现本地已下载模型，数据不出本机 |
| 其他 | 自定义 OpenAI 兼容接口 |

- **AI 续写智能衔接** — 续写时自动注入章节上文（最后 500 字），AI 回复更自然连贯

### 大纲规划
- **双视图** — 树形大纲（缩进式层级）与思维导图（React Flow 可视化）一键切换
- **拖拽排序** — 树形大纲支持同级节点拖拽重排（@dnd-kit），顺序持久化保存
- **思维导图** — 自动布局、拖拽改变层级、缩放平移、小地图导航、右键菜单
- **节点操作** — 点击标题直接编辑、折叠/展开（+N 角标）、修改节点类型、复制/粘贴子树
- **节点类型** — 故事弧 / 幕 / 章 / 场景，浅色底色 + 彩色边框，清晰易读
- **章节关联** — 大纲节点可关联到具体章节
- **搜索筛选** — `Ctrl+F` 搜索节点，自动高亮祖先路径
- **撤销/重做** — `Ctrl+Z` / `Ctrl+Shift+Z`，误删误改可恢复
- **导出大纲** — 导出为缩进文本文件

### 数据安全
- **自动备份** — 定时（每 30 分钟）导出全库数据为 .hwb 压缩文件，保留最近 10 份
- **章节历史版本** — 每 5 分钟自动保存快照，每章保留 20 个版本，一键恢复
- **备份管理** — 手动创建/恢复/浏览备份，打开备份文件夹

### 写作质量工具
- **敏感词检测** — 内置网文平台审核词库（政治/色情/暴力/赌博/毒品/自残/竞品品牌），分类标记 + 替换建议
- **重复词分析** — 扫描高频词、常见搭配、句首重复模式，柱状图可视化 + 重复率统计

### 内容管理
- **角色管理** — 姓名、别名、角色定位、详细描述、属性、关系
- **角色关系图谱** — React Flow 可视化人物关系网络，拖拽连线建关系，预设 16 种常见关系类型 + 自定义，右键删除连线，节点点击跳转详情
- **时间线视图** — 按卷/章纵向展示创作时间线，点击章节直达编辑器，全局字数统计概览
- **世界观设定** — 按分类组织地理、魔法体系、势力等设定
- **章节笔记** — 每章独立笔记区，随手记录灵感碎片
- **全局搜索** — `Ctrl/Cmd+P` 跨章节搜索
- **导出模板** — 导出前自定义书名、作者、章节标题格式、段落间距、卷名/笔记开关
- **格式支持** — TXT / EPUB 格式导出

### AI 拆书分析
- **逐章深度分析** — 对全本小说逐章 AI 分析，提取摘要、关键事件、出场人物、情绪基调
- **全局结构报告** — 聚合各章数据生成故事结构、人物弧光、节奏分析、主题分析、改进建议
- **外部文件导入** — 支持导入 `.txt` / `.md` / `.epub` 文件进行分析（最大 10MB）
- **结果导出** — 分析结果可一键导入大纲或导出 Markdown 报告
- **进度可视化** — 实时显示分析进度，支持随时取消

### 番茄钟写作
- **自定义时间** — 预设 25/45/60 分钟 + 自由输入（1-180 分钟）
- **提示音选择** — 5 种音效可选：经典滴滴、风铃、铃声、电子、柔和，支持试听
- **进度展示** — 圆形进度环 + 顶部进度条，倒计时直观
- **字数追踪** — 记录每次写作会话的字数产出

### 其他
- **版本更新通知** — 启动时自动检查 GitHub Releases，有新版本顶部通知
- **写作统计** — 每日字数、连续写作天数、每周趋势柱状图、每日目标环形进度
- **多主题写作** — 5 套编辑器背景主题 + 自由排版定制
- **打字机模式** — 沉浸式居中光标 + 行聚焦
- **暗色模式** — 明暗主题切换
- **模板系统** — 角色/设定等可复用模板

## 快速开始

### 前置要求
- Node.js >= 18
- npm >= 9

### 安装与运行

```bash
# 克隆仓库
git clone git@github.com:ylfnevergiveup/happywrite.git
cd happywrite

# 安装依赖
npm install

# 启动开发模式（热重载）
npm run dev

# 生产构建
npm run build
```

### 配置 AI

1. 启动应用后，点击左下角设置图标
2. 在「AI 配置」中选择提供商（默认 DeepSeek）
3. 填入对应平台的 API Key
4. 选择模型，点击保存

> 如果没有 API Key，推荐先使用 DeepSeek（国内访问稳定，价格低廉）或通义千问。

## 开发

### 添加新的 IPC 通道

需要修改 3 个文件：
1. `src/main/ipc/<domain>.ts` — 注册 `ipc.handle('channel:name', ...)`
2. `src/preload/index.ts` — 添加 bridge 方法
3. 渲染进程组件中调用 `window.api.<domain>.<method>()`

### 添加新的 AI 提供商

编辑 `src/main/ipc/ai.ts`：
- 在 `Provider` 类型联合中添加新 provider
- 在 `providerDefaults` 中添加 baseUrl 和模型列表
- 编辑 `src/renderer/components/Settings/SettingsDialog.tsx` 添加 UI 选项
- 如果使用 OpenAI 兼容 API，无需额外代码
